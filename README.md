# Portfólio Pessoal

Este projeto é um site de portfólio desenvolvido para apresentar projetos, trabalhos e algumas informações sobre mim. A ideia foi criar um site simples, organizado e fácil de navegar, reunindo tudo em um só lugar.

O site também foi uma forma de praticar meus conhecimentos em desenvolvimento web e aprender mais sobre a criação e organização de páginas.

## Tecnologias utilizadas

* **HTML5:** estrutura e organização do conteúdo das páginas.
* **CSS3:** estilização, cores, espaçamentos e layout do site.
* **JavaScript:** implementação de funções e interações na página.

## Estrutura do projeto

O projeto está organizado da seguinte forma:

```text
.
├── index.html
├── info.html
├── project.html
├── selectworks.html
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── main.js
```

### Páginas

* **index.html:** página inicial do portfólio.
* **info.html:** página com informações sobre mim.
* **project.html:** seção dedicada à apresentação dos projetos.
* **selectworks.html:** página com uma seleção de trabalhos.

### Arquivos complementares

* **assets/css/style.css:** contém os estilos utilizados para definir a aparência das páginas.
* **assets/js/main.js:** reúne as funções JavaScript utilizadas no site.

## Funcionalidades

O site foi pensado para facilitar o acesso às principais informações do portfólio, permitindo que os visitantes conheçam um pouco mais sobre mim e visualizem os projetos e trabalhos apresentados.

Entre os principais recursos estão:

* Navegação entre as páginas do site.
* Apresentação de informações pessoais.
* Exibição de projetos e trabalhos selecionados.
* Organização do conteúdo em páginas separadas.
* Estilização personalizada com CSS.

## Objetivos do projeto

O principal objetivo é criar um espaço para apresentar meus trabalhos e projetos de forma organizada. Além disso, o desenvolvimento serviu para colocar em prática conceitos de HTML, CSS e JavaScript, melhorar minha experiência com desenvolvimento web e aprender mais sobre a construção de sites.

## Aprendizados

Durante o desenvolvimento, pude praticar a estruturação de páginas HTML, a personalização de layouts com CSS e a organização dos arquivos do projeto. Também foi uma oportunidade de trabalhar na divisão do conteúdo entre diferentes páginas e entender melhor como esses elementos funcionam em conjunto.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
3. Abra o arquivo `index.html` em um navegador para visualizar o site.
