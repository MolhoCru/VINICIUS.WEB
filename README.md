Esse projeto é um site de portfólio criado para apresentar projetos e trabalhos.

A ideia foi desenvolver um site simples e organizado, com as principais informações reunidas em um só lugar.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript

## Estrutura

O projeto possui algumas páginas principais:

* `index.html` — Página inicial
* `info.html` — Informações sobre mim
* `project.html` — Projetos
* `selectworks.html` — Trabalhos selecionados
* `assets/css/style.css` — Estilos do site
* `assets/js/main.js` — Funções em JavaScript

## Objetivo

O objetivo do projeto é servir como meu portfólio pessoal e também colocar em prática alguns conhecimentos de desenvolvimento web.
